# Jokers

import JokerTable from '@site/src/components/JokerTable';

**76 total jokers** across two types:
- **Aura (persistent)** — Always active when equipped. Max 5 slots (6 with Sixth Sense).
- **Instant (one-time)** — Activated manually, once per day.

Most jokers can be upgraded from L1 to L3. Upgrade costs: **$5,000** (L1→L2), **$30,000** (L2→L3).
