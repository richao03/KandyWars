# Economy Constraints

| Constraint | Value |
| --- | --- |
| Persistent (aura) joker slots | 5 (6 with Sixth Sense) |
| One-time joker slots | Unlimited |
| Base inventory | 30 |
| Allowance multiplier cap | 8x combined |
| Stash interest cap | $5,000/day |
| Upgrade L1→L2 | $5,000 |
| Upgrade L2→L3 | $30,000 |
| Candy melt window | 5 periods (disabled by Deep Freeze) |
| Game length | 5 days, 8 periods/day (40 total) |
| Starting balance | $20 ($2,000 with Senior Executive) |

## Candy Unlock Progression

| Day | Requirement | Unlocks |
| --- | --- | --- |
| 1 | Start | Small candies ($0.01–$2) |
| 2 | $500 balance | Medium candies ($0.50–$20) |
| 3 | $5,000 balance | Big candies ($5–$100) |

## Difficulty Levels

16 difficulty levels. Higher difficulty = higher adoption fee (debt):
- Level 1 (Rock): $5,000
- Level 6: ~$100,000
- Level 16 (Dragon): $10,000,000
