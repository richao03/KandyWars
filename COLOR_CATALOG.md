## 🔄 Migration Strategy

### Phase 1: Create Color Constants File
Create `src/constants/colors.ts` with the consolidated palette.

### Phase 2: High-Impact Replacements (by usage count)
1. **White variations** (112 uses) → `colors.white` or `colors.offWhite`
2. **Brown** (38 uses) → `colors.brown.primary`
3. **Gray 666** (29 uses) → `colors.gray.medium`
4. **Dark backgrounds** (17+ uses) → appropriate `darkBg` colors

### Phase 3: Theme-Specific Replacements
- **Market theme:** Brown, gold, beige
- **Evening theme:** Purple, lavender
- **Tech theme:** Neon green, cyan
- **Error states:** Red family
- **Success states:** Green family

### Phase 4: Component-by-Component Migration
Update each component file to import and use the color constants.
